Flood It : RL Research

Flood it is a puzzel game where player flood the entire grid with and color for a pivot flood conner following a simple set of rules : cells having the same color as the pivot and are at the boundary of the flooded region are consumed by the flooded region

The project focuses on the developement of a flood it web game for data collection of game states, action taken by the player and moves for research based on applying Reinforcement Learning concept and method to the project for some result

Project Goals

  • Develop Flood it game for people to play in their browser
  • Collection of Game state, actions and reward from played games by user
  • Using data collected of RL based research
