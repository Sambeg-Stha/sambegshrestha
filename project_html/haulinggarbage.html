Hauling Garbage : Game Development

development of the first installment game for "Project Eclips", an small horror game following a garbage collector going to a neighbhour hood for a high paying request, where he encounters somthing weird about the residence.

The game is planned to have a retro PS1/PSX console based graphic and texture, showcasing horror element and immersive movement and gameplay. planned to relase early 2027.

This is my first attempt to a larger more planned game developement project

Project Goals and Vision

  • Develop a short horror game with retro graphic
  • Understanding and learning the game develpment process
  • Experiencing developing 3D title
  • Planning a basis for future games based on the Project Eclips
